
## Известные ограничения
- Flashscore API НЕ поддерживает `before_dt` в URL — фильтрация на клиенте
- H2H и team history МОГУТ быть историческими через client-side фильтр
- Форма/таблица — всегда ТЕКУЩИЕ (не исторические)
- Для older дат (>3 дней) scrape HTML не реализован — нужен перебор лиг
- Baseball модель отключена: низкая точность (44%) и отрицательный ROI
