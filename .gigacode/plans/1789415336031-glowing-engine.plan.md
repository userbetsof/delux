# Date Filter for Admin Panel

## Goal
Add a date range filter (`date_from` / `date_to`) to the main data pages in the admin panel: **Matches**, **Predictions**, and **Queue**.

## Approach
Use Vuetify 3's `v-menu` + `v-date-picker` to provide a date range picker. The filter will be passed as query params (`date_from`, `date_to`) to the server API endpoints, which will add `WHERE` clauses on the date columns.

## Files to Modify

### 1. `admin/app/pages/matches/index.vue`
- Add reactive refs: `dateFrom` and `dateTo` (stored as `YYYY-MM-DD` strings)
- Add a date range picker using `v-menu` + `v-date-picker` (Vuetify multi-date picker with range mode)
- Include `dateFrom`/`dateTo` in the query object sent to `/api/matches`
- Reset offset on date change

### 2. `admin/server/api/matches/index.get.ts`
- Parse `date_from` and `date_to` from query params
- Add `m.match_date >= date_from` and `m.match_date <= date_to` to WHERE clause
- Apply to both the data query and the COUNT query

### 3. `admin/app/pages/predictions.vue`
- Add reactive refs: `dateFrom` and `dateTo`
- Add date range picker to the filter bar
- Include in both `listQuery` and `summaryQuery`
- Reset offset on date change

### 4. `admin/server/api/predictions/index.get.ts`
- Parse `date_from` and `date_to` from query params
- Add `m.match_date >= ?` and `m.match_date <= ?` to WHERE clause
- Apply to both the data query and the COUNT query

### 5. `admin/app/pages/queue.vue`
- Add reactive refs: `dateFrom` and `dateTo`
- Add date range picker to the filter bar
- Include in the query object

### 6. `admin/server/api/queue.get.ts`
- Parse `date_from` and `date_to` from query params
- Add `date_match >= ?` and `date_match <= ?` to WHERE clause
- Apply to both the data query and the COUNT query

## UI Design
- Date picker button placed in the filter bar alongside existing filters (search, sport, status, etc.)
- Button text shows the selected range or "Дата" placeholder
- Uses Vuetify `v-menu` with `v-date-picker` in `multiple="range"` mode
- Compact density to fit in the filter bar
- Green primary color to match the theme

## Verification
- Test filtering by date on each page (matches, predictions, queue)
- Test with date range that matches existing data
- Test with date range that returns no results
- Test clearing the date filter
- Ensure pagination works correctly with date filter applied (total count respects the filter)
